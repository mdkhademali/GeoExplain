### class `GeoExplainModel(algorithm: 'str' = 'random_forest', task: 'str' = 'classification', params: 'dict[str, Any] | None' = None, random_state: 'int' = 42) -> 'None'`

Consistent wrapper around Random Forest, XGBoost, LightGBM, MLP, logistic/ridge and SVM.

* `.class_index(class_label: 'Any | None' = None) -> 'int'`: Encoded index (column of ``predict_proba``) of ``class_label``.
* `.clone() -> "'GeoExplainModel'"`: Return an unfitted copy with identical configuration.
* `.evaluate(X: 'pd.DataFrame', y: 'Sequence[Any]') -> 'dict[str, float]'`: Compute the standard metric set for the model's task (see :mod:`geoxplain.metrics`).
* `.family` (property): ``'tree'``, ``'linear'``, ``'neural'`` or ``'kernel'``.
* `.final_estimator_` (property): The bare estimator (unwrapped from the scaling pipeline if present).
* `.fit(X: 'pd.DataFrame', y: 'Sequence[Any] | pd.Series') -> "'GeoExplainModel'"`: Fit the model on features ``X`` and target ``y``.
* `.get_config() -> 'dict[str, Any]'`: JSON-friendly description of the model configuration.
* `.is_fitted` (property): 
* `.label` (property): Human-readable algorithm name.
* `.predict(X: 'pd.DataFrame') -> 'np.ndarray'`: Predict class labels (classification) or values (regression).
* `.predict_proba(X: 'pd.DataFrame') -> 'np.ndarray'`: Class probabilities, shape ``(n, n_classes)``, columns ordered as ``classes_``.
* `.save(path: 'str | Path') -> 'Path'`: Serialise the model with :mod:`joblib`.
* `.scaler_` (property): Fitted ``StandardScaler`` for scale-sensitive models, else ``None``.
* `.spec` (property): The :class:`~geoxplain.models.factory.AlgorithmSpec` of this model.
* `.transform(X: 'pd.DataFrame') -> 'pd.DataFrame'`: Apply the model's internal feature scaling (identity for tree models).

### `available_algorithms() -> 'dict[str, bool]'`

Return ``{algorithm: is_importable}`` for every registered algorithm.

### `build_estimator(algorithm: 'str', task: 'str', params: 'dict[str, Any] | None' = None, random_state: 'int' = 42) -> 'tuple[Any, dict[str, Any]]'`

Instantiate an *unfitted* scikit-learn compatible estimator.

### `default_params(algorithm: 'str', task: 'str') -> 'dict[str, Any]'`

Default hyper-parameters (moderate, deterministic, small-data friendly).

### `resolve_algorithm(name: 'str') -> 'str'`

Normalise an algorithm name/alias to a registry key.
