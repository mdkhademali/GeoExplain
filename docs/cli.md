## Command-line interface

`geoxplain <command> [options]` (also `python -m geoxplain`). Add `-v` **before** the command for progress messages: `geoxplain -v run --config ...`. Errors print `geoxplain: error: ...` and return exit code 2. `geoxplain <command> --help` lists every option.

Common data options: `--data CSV`, `--target`, `--features F1 F2 ...`, `--x`, `--y`, `--id-col`, `--crs EPSG:xxxx`, `--task classification|regression` (inferred if omitted). List `--features` explicitly: extra numeric columns (such as other targets in the example CSV) would otherwise be at risk of leaking into a model.

| Command | Purpose | Key options | Main outputs |
|---|---|---|---|
| `generate-data` | synthetic dataset | `--out-dir data --size 100 --n-samples 2500 --pixel-size 30 --seed 42` | `samples.csv`, `stack.tif`, `rasters/`, `truth/`, `dataset_metadata.json` |
| `train` | fit and save a model | `--algorithm`, `--params JSON`, `--out model.joblib`, `--validation none/random_split/spatial_split`, `--test-size`, `--block-size`, `--buffer`, `--seed` | model file; JSON with hold-out metrics (from a probe model; the saved model is refit on all data) |
| `evaluate` | metrics of a saved model on a CSV | `--model`, `--data`, `--target`, `--out-dir` | `metrics.csv`, `metrics.xlsx`, `confusion_matrix.csv` |
| `explain` | global and local explanations | `--model`, `--data`, `--target`, `--out-dir`, `--max-samples`, `--local 0 1`, `--class-label`, `--repeats`, `--formats png pdf` | `tables/`, `figures/` (SHAP summary/bar/dependence, permutation importance, PDP, waterfall) |
| `spatial-explain` | spatial SHAP | `--model`, `--raster stack.tif` (+ `--band-names`) **or** `--points CSV` (+ `--crs`), `--background-data`, `--class-label`, `--no-maps`, `--source "text on maps"` | `rasters/*.tif`, `maps/*.png`, `spatial_shap_summary.csv`; or `spatial_shap_points.csv` (+ `.gpkg` when `--crs` given) |
| `compare` | benchmark models + explain the primary one | `--models rf xgboost lightgbm mlp`, `--primary`, `--raster`, `--n-splits`, `--test-size`, `--block-size`, `--buffer`, `--dataset-label` | full experiment directory incl. `report.html` |
| `run` | experiment from a JSON config | `--config`, `--out-dir` | as `compare`; see `examples/example_config.json` |
| `report` | HTML report from an experiment directory | `--experiment-dir`, `--out`, `--title` | `report.html` (self-contained) |
| `info` | version, available algorithms, environment | | JSON |

## Example session

```bash
FEATS="ndvi ndbi lst elevation rainfall distance_to_water population"
geoxplain generate-data --out-dir data
geoxplain train --data data/samples.csv --target target --features $FEATS --crs EPSG:32645 --out outputs/rf.joblib
geoxplain spatial-explain --model outputs/rf.joblib --raster data/stack.tif --out-dir outputs/spatial \
                          --source "Synthetic data generated by GeoExplain"
geoxplain compare --data data/samples.csv --target target --features $FEATS --crs EPSG:32645 \
                  --raster data/stack.tif --out-dir outputs/compare
geoxplain report --experiment-dir outputs/compare --out outputs/compare/report_copy.html
```

`spatial-explain` draws the background sample from `--background-data` if given, otherwise from valid raster cells.
