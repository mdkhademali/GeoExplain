## Contributing to GeoExplain

Thank you for helping! Bug reports, documentation fixes, new examples and features are all welcome.

## Development setup

```bash
git clone https://github.com/mdkhademali/GeoExplain.git && cd GeoExplain
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest                    # full suite on small synthetic data
ruff check src tests qgis scripts reproduce.py examples
python reproduce.py --quick
```

## Guidelines

* **Open an issue first** for larger changes (new model, new output format, API changes).
* Follow PEP 8 (enforced by `ruff`), use type hints and docstrings on public functions/classes.
* **Every feature needs a test** on small synthetic data (no downloads). Bug fixes need a regression test.
* **No fabricated results.** Numbers in docs must come from executed code; the README tables are generated by `reproduce.py`.
* Do not claim causality from SHAP. Keep language about explanations precise (association / model behaviour).
* Keep QGIS code in `qgis/`; the core package must not import QGIS.
* Optional dependencies must fail gracefully with an actionable message.
* Update `CHANGELOG.md` and regenerate `docs/api.md` (`python scripts/build_api_docs.py`) when the public API changes.
* By contributing you agree to license your contribution under GPL-3.0-or-later.

## Pull requests

Branch from `main`, keep PRs focused, fill in the PR template, and make sure CI is green.
