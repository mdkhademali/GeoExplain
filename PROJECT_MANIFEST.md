## Project manifest: GeoExplain v0.1.0

Initial research release (alpha). Everything under `data/` and `results/` is **synthetic** and was produced by executing the code in this repository (`python reproduce.py`). Nothing has been published to PyPI, conda-forge, the QGIS plugin repository or Zenodo.

## Top level

| Path | Purpose |
|---|---|
| `README.md` | project overview, quick start, generated example results, figures |
| `LICENSE` | GPL-3.0-or-later (full text) |
| `CITATION.cff` | citation metadata (Ali, M. K.; ORCID 0009-0006-0917-3372; no DOI) |
| `pyproject.toml` | package metadata, dependencies, `geoxplain` console script, pytest and ruff configuration |
| `requirements.txt`, `requirements-dev.txt` | runtime and development dependencies |
| `CHANGELOG.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `AUTHORS.md` | project governance |
| `reproduce.py` | one-command regeneration of data, results, figures, report and README tables |
| `.gitignore`, `.gitattributes` | repository hygiene |
| `PROJECT_MANIFEST.md` | this file |

## `src/geoxplain/` (library)

| Path | Purpose |
|---|---|
| `models/` | `GeoExplainModel` (RF, XGBoost, LightGBM, MLP, logistic/ridge, SVM), algorithm factory |
| `metrics/` | classification/regression metrics, metric tables, CSV/Excel export |
| `validation/` | random and spatial splits, `SpatialBlockKFold`, random-vs-spatial comparison, Moran's I, semivariogram |
| `explainers/` | `GeoShapExplainer`/`ShapValues`, permutation and built-in importance, partial dependence |
| `spatial/` | prediction rasters, uncertainty, **spatial SHAP** (`compute_spatial_shap`) |
| `io/` | `GeoDataset` loading/validation, `RasterStack`, CRS-preserving GeoTIFF writing |
| `datasets/` | reproducible synthetic scene generator |
| `visualization/` | academic style, cartographic maps, statistical plots, diagrams and logo |
| `workflows/` | `run_experiment` (end-to-end) and `build_report` (HTML) |
| `utils/` | exceptions, optional-dependency handling, seeding/environment capture, JSON helpers |
| `cli.py`, `__main__.py` | `geoxplain` command-line interface |
